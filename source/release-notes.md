uTube by kharrison, based on Opaline by verback2308.

- uTube now installs as its own app alongside Opaline, using the separate com.kharrison.utube app identifier.
- The Open in uTube share action uses its own link handler so it opens uTube when both apps are installed.
- The kharrison Apps source now offers the standalone uTube build. Older builds that shared Opaline's identity are no longer offered in the source.
- Refreshed the GitHub page with uTube's features, icon, installation instructions, and credits. Removed upstream promotional and donation buttons.
- Jailbreak packages also use their own package ID and app folder.

Install uTube from the refreshed kharrison Apps source as a new app. You can keep Opaline or the older uTube installation. Settings, downloads, and sign-in from the older installation do not transfer automatically; connect your account in the new app. Future uTube updates use this new identity.

Wall, Carousel, inline comments, YouTube notifications, customizable controls, and AirPlay behavior remain available.
