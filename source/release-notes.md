uTube by kharrison, based on Opaline by verback2308.

- New Wall layout: a dense, staggered thumbnail canvas with two-dimensional scrolling and pinch to zoom.
- New Carousel layout: swipe between animated video cards, with muted previews and a Play button that opens the standard player.
- Browsing either layout preserves the current full-size or minimized video. Carousel previews stay off while the main player is in use, AirPlay is connected, or the app is inactive.
- Redesigned YouTube notifications with profile photos, video thumbnails, unread highlighting and replies directly inside the inbox. Replying loads and validates the linked thread before enabling Send; drafts survive closing the panel.
- Refreshed video comments with larger text and avatars, neutral sort chips, blue reply controls and an avatar beside the inline composer.
- AltStore now uses a fresh icon URL for the matching custom uTube artwork.

Choose a layout in Settings → Home Layout. Existing Shelf Rails and Plain Grid remain available. Notification replies use the YouTube account already connected for commenting; no Google app registration is added. Removed or unavailable threads show a retry message instead of sending to a guessed comment. Receiver-specific AirPlay behavior and signed-in notification replies still need confirmation on a device.
